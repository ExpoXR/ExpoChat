Snapshots, backups & history
Snapshots restore workspace files. Database backups preserve chats, plans, settings, and metadata. They are separate safety layers.

                

                  

                    
Snapshots

                    
Created before destructive file actions and selected run stages. Active-run snapshots stay protected.

Backups

                    
Database backups are operator-managed. Use make backup or volume-level backup scheduling. Snapshot archives do not replace database backups.

                    
Database and snapshot volumes should be backed up together.

                  

                  

                    
Timeline & rescheduling

                    
Timeline tracks file paths and diffs. Failed or cancelled runs can resume; completed work can clone into a new run. Automatic calendar scheduling is not enabled.
